# LeetCode Practice

Repo buat belajar solve algoritma dari LeetCode.

## Cara Menjalankan Test

### JavaScript
```bash
node nama_file.js
```

### TypeScript
```bash
npx ts-node nama_file.ts
```

### Python
```bash
python nama_file.py
```

### Java
```bash
javac nama_file.java && java Solution
```

## Format Nama File

```
{nomor}_{DD-MM-YYYY}.{ext}
```

Contoh: `1_22-05-2026.js`, `2_22-05-2026.ts`, `3_22-05-2026.py`, `4_22-05-2026.java`
